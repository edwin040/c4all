# LUMINA UI

A universal Android customization app focused on beautiful wallpapers, useful home-screen widgets, and a calm Liquid Glass-inspired visual language.

## First milestone
- Jetpack Compose app dashboard
- Persistent Light Mode and Dark Mode
- Animated ambient live wallpaper (LUMINA Flow)
- Home-screen clock/date widget
- GitHub Actions debug APK build

## Build
Run the **Build LUMINA UI APK** workflow from the Actions tab, or push to `main`. Download the `lumina-ui-debug-apk` artifact after the workflow succeeds.

## Compatibility
Designed for Android 6.0+ (API 23+). Actual widget appearance and wallpaper performance depend on the device and launcher. System UI replacement is not included; Android restricts those surfaces for ordinary apps.
